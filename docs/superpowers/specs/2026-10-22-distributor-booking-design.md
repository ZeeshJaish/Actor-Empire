# Existing distributor booking and competition revision

Approved scope: use the existing cinema distributors/chains and release selections. No cinema construction, expansion, acquisition or management feature. No hard gross, budget-return or theatrical-age cap.

## Supply and booking

Partition each chain's existing regional screens using the complete canonical country registry and fixed baseline population/access weights. A partial input, weekly seed, changed release footprint or population movement must not move physical screens between countries. Current economy continues to set automatic ticket prices and current participation controls demand.

Separate audience demand from an exhibitor's weekly schedule. Opening booking uses public awareness, package expectations and relevant local audience; renewals use observed local attendance and current public demand. Share real screen-days across every owner. Compare expected exhibitor contribution per screen minute, with bounded discovery bookings and feasible minimum show blocks. Operating-cost estimates guide bookings only; they are not a second producer expense. Charge existing producer booking terms once through the existing settlement.

Store only compact optional booking observations on existing title/pool runs. End nonviable local bookings after repeated weak results, preserve films denied physical access, and retain profitable local runs without a fixed maximum. No omniscient unreleased quality in opening booking. A discovery allowance is limited to the actual selected footprint and never manufactures audience.

## Streaming alternatives

Project a read-only, country/cohort-specific alternative from existing offers, committed customers, playable catalogue and measured playback. Rival films compete for existing cinema resources; relevant streaming alternatives compete for willingness/attention. Combine alternatives once with the existing outside choice. Distinguish another title at home from waiting for this film's publicly known signed window. Missing local access is not a competing offer. Multiple subscriptions or repeat starts are not additive unique people. Preserve cinema/streaming money partitions and all canonical platform settlements.

Use an immutable pre-cinema projection and previously committed viewing evidence, avoiding a same-week cinema/streaming feedback cycle. Actual earlier-title viewing can still support earned universe familiarity.

## Safety and calibration

Upgrade known prior tuning versions for future unsettled weeks. Preserve historical receipts, source IDs, cash, closed titles, audience history, paid publicity, signed dates and backend obligations. Do not restart an old release's opening or infer invented cast/viewing facts. Continue verified current/previous save generations and exactly-once settlements for player, offered-role and NPC ownership.

Calibrate with the complete 197-country mixed-cohort audience, competing cinematic slates and accessible rival platforms. Compare same-spend campaign treatments, small local/targeted/sleeper films, strong/weak stars, earned/unearned/weak universes, affordability and misleading repeated delivery. Report distributions of gross, producer receipts, all-in theatrical profit, occupancy, paid repeats and run lengths. Do not impose hit quotas. Local duration bands are diagnostic expectations, not forced exits. Keep previous three-country reports explicitly historical.

Recheck the actual App release/financial/insight flow, save/reload/retry, signed payments, long saves and matched early/late performance before calling implementation verified. Desktop evidence is separate from physical-device validation.
