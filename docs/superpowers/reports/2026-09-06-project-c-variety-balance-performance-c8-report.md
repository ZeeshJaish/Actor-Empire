## Reported bug and root cause

The real weekly simulation completed, but persistence rejected its result with:

`Save compaction rejected: industry intelligence state changed`

The first generated industry-intelligence record legitimately omitted optional fields. Compaction rebuilt those records with own properties whose values were `undefined`. Save integrity correctly distinguished an absent property from an own property, so it rejected the altered shape and the UI showed `Week Processing Failed`.

The repair preserves optional-key absence during industry-intelligence normalization. The protection is covered by the industry-content save regression and a new twelve-week fresh-save audit that executes the real game loop plus the same verified persistence preparation used by autosave.
